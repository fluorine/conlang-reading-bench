Can AI read a new language?

Give a model a tiny story in a made-up language, then ask who has the key. How much help does it need to follow the story?

A story from the test

Cy numa vema

Ada numa kato

Ada-ak kato Bo-es poma

Bo-ak kato Cy-es poma

Who holds the key at the end?

Reveal the answer

Cy. Ada starts with the key, gives it to Bo, and Bo gives it to Cy. The coin stays with Cy the whole time.

Reading conditions

Tier 2 · Four transfers.

The coin and key change hands in alternating events. One question asks who held an object when the other was given away for the second time.

All four models were scored on the same 48 stories, with 192 questions per condition. GPT-6 Luna used a 2,048-token cap. The other models used 64 tokens.

GPT-4o mini (default) scored 42.71% with minimal clues and 79.69% in the English control.

GPT-4.1 mini (default) scored 39.58% with minimal clues and 74.48% in the English control.

GPT-5.4 nano (default) scored 34.90% with minimal clues and 61.46% in the English control.

GPT-6 Luna (low) scored 100.00% with minimal clues and 99.48% in the English control.

Tier 3 · New grammar.

In this exploratory test, five objects change hands in a made-up language. The model must work out how shared word endings convey who gave which object, then answer one question about the final holder.

Each accepted story is checked for one answer under the stated rules. English versions tell the same stories. The scores use 48 stories per model and should not be compared directly with the earlier tiers.

See the comparison, shortcut baselines, and full limitations

Tier 4 · Longer stories.

Five objects change hands 30 times in an invented language. Models answer four questions about the final holders without a glossary of suffix meanings. The rules and starting positions are supplied, and a checker confirms the answers are determined by the story.

The graph shows 192 answers per configuration, plus an English control. We also test the same questions with the full grammar disclosed. The results measure this task, not overall intelligence; the sample is small and model aliases may change.

The method

From a story to a score.

All four models saw the same held-out stories. The earlier models used default effort, temperature zero, and a 64-token cap. The original pilot used GPT-4.1 mini (April 2025) and GPT-4o mini (July 2024). The follow-ups used GPT-5.4 nano (March 2026) and GPT-6 Luna with low reasoning and a 512-token cap that includes reasoning.

How to read the gap

In the original pilot, GPT-4.1 mini led GPT-4o mini by 19.79 percentage points overall. The 95% interval across these stories was 11.46 to 28.13 points. Both original models fell short of the 90% English target during development, so the comparison is exploratory.

How do other benchmarks compare?

Dyna-bAbI
Generates stories and questions to test reasoning about events. Here, the same events also appear in an invented language, so we can measure what grammar clues add. Dyna-bAbI paper
ConlangBench
Tests models on 21 existing constructed languages. Here, each test story gets a freshly generated language with its own vocabulary and grammar. ConlangBench paper
SILICA
Asks models to recognize when clues leave a language puzzle unsettled. Here, the generator applies that check before a story reaches the model, so every scored question has a definite answer. SILICA examples
